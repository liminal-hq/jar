# Jar

A tiny simulation in a box. A floating desktop aquarium/terrarium with a few auto-named critters who live, sleep, breed, age and pass on in real time.

Read `SPEC.md` and `SCREENS.md` for product behaviour, `docs/architecture/3d-engine.md` for the rendering/physics/AI stack, and `docs/architecture/rust-core.md` for the Rust simulation core. `AGENTS.md` and `CLAUDE.md` cover contributor conventions.

## Status

Spec and repository scaffold stage — see `AGENTS.md` → Project Status. **Picking this up to implement it? Start with `NEXT_STEPS.md`** — it says exactly what's real vs. stubbed and where to begin.

## Getting started

```bash
bun install
bun run tauri dev
```
