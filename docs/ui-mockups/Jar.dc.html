1cScreen map for the Tauri build (full detail in spec.md)
Window 1 · tank
Transparent, frameless, always-on-top, resizable. The frame bezel runs edge-to-edge and is the drag handle. Hover → drawer slides out from behind (light, bubbles/mist, sound, mode, tree, setup, exit).
Window 2 · critter card
Spawned on click, beside the tank. Rename · mood/energy · trait · genetics · favourite spot · lineage · memorial state.
Window 3 · family tree
Generation rows · living + memorial nodes · click → card.
Window 4 · setup
Mode · frame · dialog theme + variant · tank toggles · simulation speed (slider, Real time snap) · add critter.
Dialog themes
Modern (default) · Modern dark · Classic 98 · Paper notebook · Handheld LCD · Neon terminal. Applies to windows 2–4 and the drawer; independent of the tank frame. Modern/Modern dark follow the OS light/dark preference by default.
Mobile · companion
Read-only jar + resident list; tap → card as a sheet. Home-screen widget shows a jar snapshot.
Targets
Linux (GNOME, Cinnamon) · Windows · Android. GNOME has no tray by default → show/hide also lives in Setup.
Sim rules
Real time, 1 jar-day = 2 min · sleeps 21:00–07:00 by system clock at real time, by jar time when sped up · adults breed awake under the cap · elders pass gently, stay in the tree · state saved every tick.
